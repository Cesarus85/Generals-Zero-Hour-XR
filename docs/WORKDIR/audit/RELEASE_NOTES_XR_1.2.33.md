# Generals: Zero Hour XR 1.2.33 preview

This public offline preview adds the accepted spatial command-console redesign
and native Quest text entry while retaining the 1.2.28 performance baseline.

## Changes since 1.2.28

- Redesigns the spatial UI and Commands windows with a consistent military-console visual language.
- Makes the UI, Commands and Ground View shortcut plates transparent outside their visible shapes.
- Opens Meta's runtime-owned native keyboard for original game text fields, including LAN player name, chat and Direct Connect address entry.
- Supports visible controller-ray interaction, confirmation and safe return to the game from the native keyboard.
- Keeps Campaign, offline Skirmish, Ground View, controller commands, localization and game-data import behavior intact.

## Scope and requirements

- Meta Quest 3; native ARM64 OpenXR build.
- Offline Campaign and AI Skirmish remain the supported preview paths.
- Supply your own legally obtained complete Generals and Zero Hour game files. No retail game data is included.
- Human multiplayer remains experimental and is not release-ready; native text entry does not resolve the known simulation mismatch.
- This is an independent community project, not an Electronic Arts product or endorsement.
