# Development Diary - October 2026

## 2026-10-01: Steam Frame probe build (OpenXR 1.0 fallback, runtime logging)

First step toward running the Quest APK on Valve's Steam Frame through its
Android layer (Lepton, SteamVR Android OpenXR runtime). Community reports say
that runtime implements OpenXR 1.0 only and rejects the 1.1 request that
`XR_CURRENT_API_VERSION` (1.1.45 from vcpkg) produces. `XrHello.cpp` now
retries `xrCreateInstance` with `XR_API_VERSION_1_0` on
`XR_ERROR_API_VERSION_UNSUPPORTED`; nothing in the XR layer uses 1.1 core
features. Diagnostics only, no behavior change on Quest: the full runtime
extension list, the supported environment blend modes and the bound
interaction profile per hand are logged (`gx-xr` tag and
`generals-xr-stderr.log`). Local debug APK `1.2.36-frame-probe.1` (10236)
built from branch `claude/steam-frame-probe`; not yet run on a Frame or a
Quest.
